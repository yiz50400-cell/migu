## 本次修复

- 分离私有 installation.json 与公开 installation.example.json；加入按路由只读预检和安装说明。
- 去除剪辑 skill 对作者机器目录的依赖，改为本次交接或本机配置定位工具箱。

- 全解码时排除封面流并归零视频时间戳，避免偏移时间戳污染时长计算。
- 剪辑清单辅助脚本改用 timezone.utc，解决旧 Python 不提供 datetime.UTC 时启动失败。
- 明确无声版本不强制字幕、已有干净输出不强加卡片/CTA、画幅规格服从当前任务。

## 流程文本复核

以下是人工阅读规则的一致性复核，不是代理实际执行通过率测试：

| 场景 | 当前约定 |
|---|---|
| 给定本地视频/具体链接 | 使用该参考的结构、节奏和重点，通常最多 6 个真实分镜；不代找替代片、不套 25 秒上限，也不拆成二十多镜。 |
| 客户要求找爆款 | 调采集项目，默认优先 15–25 秒；热度仅引用真实可见数据。 |
| 任意商品类别 | 重新识别商品用途和结构，保留镜头职责，按产品实际操作适配。 |
| 图片与视频配置 | 分别检查与确认，同一任务已确定部分不反复询问。 |
| 生成失败/超时 | 保存状态并恢复原任务；不重复提交冒充轮询、不退化成图文幻灯片。 |
| 成片完整性 | 对照原片检查结构、节奏和重点是否保留；真实分镜通常最多 6 个。另检实际切镜、穿帮、对应国家语言、视频包装（需复刻的画面文字）、字幕和最终导出。生成成功不能算完成。 |
| 静音成片 | 按当前要求静音，无 BGM，不捏造口播字幕。 |
| 只分析/只素材 | 不扩展成付费生成或额外剪辑。 |
