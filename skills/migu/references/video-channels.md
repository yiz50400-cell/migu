# 视频渠道与图片模型

## 图片固定模型

图片一律走客户已配置接口上的 `image2.5flare`，不改用 Hypit 图片配置，也不先走 ChatCut 图片入口。只读定位已有 Key/URL，密钥只从现有凭据存储读取，报告里只记是否存在或长度，不写内容。配置缺失、多个接口无法辨明、或更换收费账号/端点时才询问。

## 视频可多渠道、多账号

视频不必只走一个渠道或一个账号。`installation.json` 的 `video_channels` 可列出多个渠道，例如已配置的 API 视频端点，以及本机已安装的 Hypit。每个条目只记渠道 id、类型（`api` 或 `hypit`）、端点或启动器名称、账号代号、是否启用、凭据是否存在；不写密钥。

API 视频路线按已配置接口直接调用，**不再依赖 Hypit Runtime**。没有配置 API 视频渠道的旧环境，仍可把已安装的 Hypit 当作视频渠道使用。安装入口会继续复用或安装官方 Hypit，不要无故拆掉已经可用的 Hypit 路径。

## 切换对接

某个渠道或账号不可用时，先保存已完成的分镜、素材和台账状态，再切换到下一个可用渠道或账号。切换前核对该渠道的时长、参考输入和费用能力，费用或能力变化时再确认。使用 `skills/migu/scripts/video_channels.py` 做选择和故障转移。

不得把不可用渠道换成 Dreamina、ChatCut AI 生成或纯图文剪辑来冒充 AI 动态复刻。没有可用渠道时保留进度并说明阻塞，不交付假成片。
