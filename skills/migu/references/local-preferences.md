# 本机用户已确认的复刻偏好

来源：本机用户于2026-11-19对migu制作流程的明确纠正。用于本用户的后续任务；新指令优先。不包含凭据或无限付费授权。

- **图片接入**：默认使用本用户已配置的Key和URL，以及本次指定的图片模型。不要求用户每次重复“利用已配置的key和url”；不因视频使用Hypit就把图片也交给Hypit，亦不先走ChatCut图片入口。只读定位配置并核对模型及所需参考图能力；确实缺失、多个配置无法辨明或需更换收费账号/端点时才询问。密钥只从现有凭据存储读取，不复制到技能或制作文件。
- **参考搜索**：先限定同一细分品类，确认用途、使用部位和演示方式相近，再比较真实热度、结构和节奏。同款、同SKU、同品牌不是条件；不能以同属“商品”或“美妆”、动作相似、节奏好为由放宽品类。面部精华可以参考其他品牌/成分的面部精华，不能跳到拖鞋；护发精华也不能仅因名称含“精华”便算同类。无合格候选就说明情况并继续有界搜索，扩大到其他细分类别须先取得用户明确选择。
- **国家含义**：用户说巴西、墨西哥等，默认指定成片口播文案、发音、字幕及屏幕文字的本地语言。参考可来自任何地区和语言；不自行添加该国家素材、作者国籍或演员国籍的筛选。额外地域要求以用户明确指令为准。
- **先展示再确认**：找到拟复刻的爆款后，先把可播放的原视频发给用户，并附可核实热度、时长和简短选择理由。等用户实际确认该条，才锁定参考、生成图片和视频。只发缩略图、自己在内部写“选定”、已获模型/费用授权，都不能替代参考确认。用户已直接指定参考时无需重复确认。
- **复刻质量**：按选定原片逐镜复刻开头吸引点、镜头顺序/职责、动作过程、景别/运镜、切点、速度、时长关系及收尾；替换为用户商品和已约定人物，语言按目标国家调整。不能把几个类似动作的通用拼接当作完美复刻。技术做不到的差异必须如实呈现，不承诺未经验证的完美一致。
- **不靠循环省积分**：按所需独立镜头生成足量素材，不用相同素材重复回放、慢放、冻结补时长；不因省积分减少必要镜头。相同动作再次出现也需要对应的新表演，除非原片明确循环且用户认可或明确要求重复。身份参考图可以共用，动态镜头充数不可以。
- **预算与反馈**：先按忠实复刻需求确定素材数量，再透明报出费用；既有预算覆盖就执行，超出时说明补齐哪些镜头及增量，不擅自降低质量，也不把“不用省积分”解释成无限预算。反馈“慢/重复”优先纠正镜头与节奏，不自动删掉原片结构。只有明确要求缩短时才作为短版制作。

流程：锁定同一细分品类及相近用途 → 跨地区找该类爆款 → 发原视频及依据 → 用户确认 → 按原片拆解足量独立镜头 → 图片用已配置Key/URL → 按已确认视频方案生成 → 目标国家语言的口播/字幕 → 与原片逐镜验收。
