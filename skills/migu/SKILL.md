# migu

作为总流程入口，协调现有采集项目、`hypit` 和 `tiktok-product-video-editor`。支持各种商品，先辨识本次商品和动作，不继承旧客户的产品、演员、账号、语言或预算。用户只要拆解、提示词或素材时，按该范围完成；要求复刻出片时，持续执行到真实成片和验收。

## 商品范围与适配原则

本流程适用于美妆个护、服装配饰、家居收纳、厨具、数码、工具、宠物用品等各类商品，不绑定护发油或其他单一品类。每个新任务重新识别当前产品的结构、真实使用方法、关键演示和身份约束，再映射参考视频的镜头职责。下文操作例子只用于说明规则，不能变成所有商品共用的镜头模板。

保留参考的完整结构和节奏，按当前产品正确用法生成动作：例如按实际包装取用液体、按服装实际开合方式穿戴、按工具真实控制方式操作、按收纳产品真实结构展开。只选择与本次产品相关的动作，不默认安排取油、涂抹、梳理、人物口播或前后对比。若两产品用途不同到无法实现同一演示目的，先说明这一实质冲突；不能编造产品功能硬套参考。

## 默认复刻标准：完整结构和节奏，操作适配当前产品

客户说“复刻／照着做／同款／只换人物和产品”，默认保留原片完整的叙事结构、镜头职责和顺序、关键演示过程、景别变化及剪辑节奏，按当前产品真实结构调整操作。不自动解释为逐像素、逐帧、相同手势轨迹或在原视频上局部替换。客户进一步澄清的效果要求优先于先前概括用语。

将改变分为三类，不能混为一谈：

- **已要求的替换**：人物、产品、市场语言、声音等，直接落实既有决定。
- **必要产品适配**：取用、穿戴、开合、装配或操控方式按当前产品真实结构调整，握持随尺寸形状调整，标签随包装替换，口播按已确认语言及商品事实调整。在保持相同镜头职责、步骤完整性和节奏的前提下自主执行，简述或记录即可，不逐项询问，不据此重新选模型或另找视频局部替换工具。
- **实质改变**：删关键步骤、合并到丢失演示过程、重排叙事、大幅缩短、改商品卖点、改选参考、改变用户特别锁定的机位/画面，或更换收费账号/超预算。先修方案；确需改变约定时才请求决定。

独立记录参考全片各镜头及动作阶段，再做新片映射，避免只写五步摘要便省掉中间过程。逐镜对照用于检查完整性和节奏，不用于追求无意义的几何一致。各镜头时长/切点以原片为节奏参考，可为动作完成、自然表演和语言适配小幅调整并记录，不能借此擅自缩成摘要版。

仅当客户明确要求指定动作轨迹、精确切点或原视频编辑等特殊控制时，核对该能力并说明具体限制。一般结构/节奏复刻在已确认模型与预算内推进，不因不能保证逐帧相同而停工。不能用图文剪辑替代真实 AI 视频，也不能将生成动作失败包装成“必要产品适配”。

## 先锁定任务，不改变交付物

将有效需求记入当前项目 `BRIEF.md`：商品及身份参考、参考来源、市场/语言、画幅、时长、必需动作、声音、交付类型、已同意的配置与付费范围。复用同一制作任务已有决定，不反复询问。

| 客户需求 | 应走的路线 |
|---|---|
| 给本地参考视频或具体视频链接，让你复刻 | 直接读取或下载这一条；不搜索替代参考。保留完整参考的结构和时长，除非客户明确要求缩短。 |
| 明确让你“找一个 TK 爆款再复刻” | 使用配置的采集项目寻找候选，再用 yt-dlp 下载和核验；默认优先 15–25 秒。 |
| 仅有商品，要求原创 AI 视频 | 自行设计商品演示；不因缺少爆款参考而自动发起搜索。 |
| 仅拆解、仅提示词 | 输出对应分析或提示词，不调用付费生成。 |
| 只要 AI 素材 | 完成生成、下载和素材 QA，不自动剪辑成广告。 |
| 复刻成片、直接出片、或要求剪辑 | 生成可用动态素材后，必要时调用现有剪辑 skill 完成输出；不要求客户再次下达“继续剪辑”。 |
| 仅剪辑现有本地素材 | 直接调用剪辑 skill，不为完成剪辑新增 AI 生成。 |

15–25 秒仅是“主动找参考”的默认筛选范围，不是客户给片的硬上限，也不是每次模型请求时长。客户给较长原片，就按该原片规划，不能擅自交付短摘要。若客户另有时长要求，按其要求。

## 流程

1. **确认输入和配置。** 对真正使用 Hypit 的任务，读取本机 `hypit` skill 和 [Hypit 配置与执行](references/hypit-execution.md)。只读定位已有配置，分别列出图片模型和视频模型的名称、用途、配置来源及凭据状态，再合并询问是否沿用；未找到的类别明确写未配置，不能只查到视频配置就宣称配置齐全。需要生图但缺图片配置时询问是否补配；本次无需生图则说明原因并标记不使用。等实际答复再使用所选账号，不把沉默当同意。已在本制作任务中明确选定的类别直接复用；只确认过视频模型时，仅补问尚未确认的图片模型。等待期间可继续本地参考拆解。
2. **按需取得参考。** 只有客户明确要求寻找爆款才走 [采集参考](references/reference-acquisition.md) 的搜索分支。给定链接的单条下载属于读取客户参考，不属于自动找爆款。保留真实来源、时长和观察数据。
3. **拆解和锁定。** 读取 [分镜与复刻](references/remake-production.md)。先从原片独立建立 `REFERENCE-SHOTS.md`，再建立逐镜 `SHOT-MAP.md`，覆盖完整时间线及各镜头动作阶段、机位、构图、节奏、字幕/叠画。生成前保存 `FIDELITY-REVIEW.md` 的计划对照结果；口播按客户要求处理，不凭截图编造对白。
4. **实际生成。** 使用 Hypit 对必需动态镜头发起视频生成，按动作、镜头和当前模型能力拆段。先完成必要的产品/演员参考图，再依赖它们生成视频。关键帧图片、缩放平移照片、图文模板和借用原片都不算完成 AI 动作复刻。
5. **下载与验收素材。** 保存 Build/任务记录、输出名、生成文件和哈希，检查真实动作、产品一致性、画面及可用区间。按 [检查与剪辑交接](references/qa-and-editing.md) 填写清单并运行检查脚本。素材不足时回到缺少的动作，不直接用静态图填空交差。
6. **完成剪辑或素材交付。** 若请求成片且需拼接、裁切、字幕、声音或排版，读取 `tiktok-product-video-editor` 并执行。把通过检查的本地生成视频作为本制作任务授权交给编辑器的素材；采集/生成由本流程承担，剪辑模块仍只处理本地素材。单段生成结果已满足完整成片要求时，直接验收交付，不强行再渲染。
7. **最终验收。** 检查完整动作、时间线、叠画边界、人脸/手/产品完整性、音轨及实际文件。导出成功只是待复核状态；通过复核后才称“完成”。返回真实成片位置、素材位置、已验证事项及剩余限制。

## 不得绕过的完成条件

- 请求 AI 复刻，必须有对应的真实 AI 视频输出和生成记录。生成失败、配置缺失、额度不足时保留进度并说明阻塞，不改交图文视频。
- 原片完整结构、镜头职责及关键动作过程都有对应；必要产品适配直接执行并记录，实质偏离另行处理。最终对照原片检查完整性与节奏，不能只检查自己简化后的分镜。
- 关键人物和产品保持连续；改演员按本次要求创建并固定参考，分段不每段随机换人。
- 不机械按 15 秒切块；短动作可单独生成，长动作可连续规划。模型最小时长与成片使用时长分开记录。
- 只复用本项目已核实素材。复用配置不是付费授权；预算明确且覆盖的工作继续执行，超出约定才请求新决定。
- 超时先恢复查询，不能重复 `hypit build` 当作轮询。记录已发生及可能已承诺费用，成功素材不重生。
- 声音遵守本次指令。没有声音约定时，在配置询问时一并明确“静音／口播”；“不加音乐也不加口播”则交付无声版本。接入现有编辑器默认无 BGM。原生 AI 口播失败时不悄悄后配音。
- 不自动发布、不自动创建定时任务；不将客户素材、密钥、Cookie 或账号配置写进 skill。

## 本机依赖与复用

首次安装见 [安装与环境检查](references/setup.md)。读取本 skill 的 `installation.json` 定位采集项目与剪辑工具箱，只存本机路径，不存模型密钥；发布版仅带 `installation.example.json`，缺少本机配置是待设置状态，不能据此认定 Hypit 未安装或账号不存在。路径不存在时定位已有安装；无法定位才说明缺项。读取对应项目说明及当前工具帮助，不猜命令或接口。`hypit`、`tiktok-product-video-editor` 属于运行依赖；仅安装 Migu 不等于安装这些程序及其运行环境。

客户迁移时仅重配本机路径、Hypit Runtime 和客户自己的凭据。见 [执行清单与恢复](references/progress-and-evidence.md)。不要加载旧 `ai-video-generation` 的 Dreamina 默认路线；仅在客户明确选择其他平台时另行处理。
